Neural networks are computational models loosely inspired by the human brain. They consist of layers of interconnected nodes, each performing simple mathematical operations. Together, these layers can learn to recognise patterns in data — from handwritten digits to spoken words.

How learning happens

Training a neural network means adjusting millions of numerical weights until the network's output matches the desired answer. This is done through backpropagation — a method that calculates how much each weight contributed to the error, then nudges it in the direction that reduces that error.

The process repeats over thousands of iterations called epochs. With enough data and compute, the network gradually improves — a phenomenon called convergence. Modern networks like GPT and BERT use this same core idea, scaled up enormously.

Layers explained

A typical neural network has three kinds of layers. The input layer receives raw data — pixel values, token embeddings, or sensor readings. Hidden layers transform this data through learned representations. The output layer produces the final prediction.

Depth — the number of hidden layers — is what gives deep learning its name. Shallow networks can approximate simple functions; deep networks can learn hierarchical features like edges, then shapes, then objects in an image.

Activation functions

Without activation functions, a neural network would just be a fancy linear equation no matter how many layers it had. Activations like ReLU introduce non-linearity, letting the network model complex, curved decision boundaries.

ReLU simply outputs zero for negative inputs and passes positive inputs unchanged. Despite its simplicity, it works remarkably well in practice and is the default choice for most modern architectures.

Overfitting and generalisation

A network that memorises training data but fails on new examples is said to overfit. Techniques like dropout — randomly disabling neurons during training — force the network to build redundant representations and generalise better.

Regularisation, early stopping, and larger datasets all help combat overfitting. The tension between fitting training data well and generalising to unseen data is one of the central challenges of machine learning.

Where neural networks are used today

Neural networks power image recognition in smartphones, real-time translation, fraud detection in banking, protein structure prediction in biology, and the large language models behind modern AI assistants. The underlying maths has not changed dramatically since the 1980s — what changed is compute, data, and engineering craft.
